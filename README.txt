THE ENCHANTED ARMORY — iPHONE INSTALL GUIDE

1. On a computer, visit https://app.netlify.com/drop
2. Drag the entire 'enchanted-armory-app' folder onto Netlify Drop.
   (Or drag the ZIP file if Netlify offers ZIP upload.)
3. Netlify will give you a public HTTPS web address ending in .netlify.app.
4. On your iPhone, open that exact address in Safari.
5. Tap Safari's Share icon, choose Add to Home Screen, and choose Add.
   If shown, enable 'Open as Web App'.
6. Tap the Armory icon on your Home Screen. You can generate and save weapons.

IMPORTANT:
- Do not upload the README alone: upload the entire app folder or ZIP.
- Once installed and visited online, the app can work offline using a service worker.
- Your saved vault is stored in browser storage on that device. Clearing Safari
  website data or deleting the web app may erase it; export backups regularly.
- Netlify's public link can be accessed by anyone who has the URL. No account
  database is needed; the app has no analytics or external connections.
- This is a home-screen web app (PWA), not an App Store native iOS app.
- For the chance calculation: major quirk = MIN(100%, curse chance + 50%).
